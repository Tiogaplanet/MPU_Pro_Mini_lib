# Changelog

All notable changes to the MiP Power Up: Pro Mini library will be documented in this file.

## [1.0.1] - 2026-08-05
- This is a time-late release of a codebase that was finalized in approximately 2018. This release is the last of a monolithic codebase in which all functionality was provided in a god class of over 2,600 lines of code. It is preserved for posterity. All future releases will use a modular construct resembling that of the MPU-D1 mini library.
